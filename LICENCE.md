## 🧩 About

**Path of Exile Client** is a comprehensive companion tool for Path of Exile featuring overlay HUD, build planner, trade helper, loot filter automation, map tracker, and stash search enhancements.

Based on popular tools like **Awakened PoE Trade**, **PoB**, and **Exilence Next**.

---

## ✨ Features

### 🎮 Core Tools
- Overlay HUD — real-time life, mana, and flask status
- Build Planner — plan passive trees and gear offline
- Trade Helper — price check items with one hotkey
- Map Tracker — track map completion and atlas progress
- Loot Filter Automation — auto-update and swap filters

### 🎨 Interface & Overlays
- Custom Overlay Skins — adjust colors, fonts, and opacity
- Stash Search Enhancements — highlight items by affix tier
- Minimap Icons — mark important league mechanics

### 🏋️ Practice & Analysis
- DPS Calculator — estimate damage against bosses
- XP Tracker — monitor leveling progress per zone
- Currency Ratio Helper — track chaos and divine exchange rates
- Death Recap — review damage sources after death
